Проект: Проектирование и разработка интерактивной информационной системы «MusicMatch» для автоматизированного анализа и многокритериального подбора музыкальных дистрибьюторов на российском рынке.

1.1. Ф.И.О. разработчиков. - Манукян Артём Артурович, Калязин Владислав Александрович

1.2. Группа. – ЛПЦ24-ОБ-ПМ1

1.3. Тема разработки: Разработка веб-ориентированного программного комплекса «MusicMatch» для автоматизированной агрегации, структурирования и комплексного многокритериального анализа данных о цифровых дистрибьюторах медиаконтента.

1.4. Цель проекта: Проектирование, алгоритмизация и программная реализация интерактивной информационной системы на базе клиент-серверной архитектуры, предназначенной для автоматизированного анализа, комплексного средневзвешенного оценивания и подбора оптимальных дистрибьюторов цифрового контента под специфику конкретного пользователя.

1.5. Задача: Провести системный анализ рынка цифровой дистрибуции в РФ, сформировать функциональные требования к ПО, спроектировать архитектуру и In-Memory модель данных, реализовать серверную часть на Flask с алгоритмами расчета рейтингов на NumPy, разработать SPA-интерфейс на чистом JavaScript и провести экспериментальное тестирование системы.

1.6. Аннотация: Данный проект посвящен проектированию и разработке интерактивной информационной системы «MusicMatch», реализующей математические модели средневзвешенного оценивания коммерческих, технико-логистических и экспертно-сервисных параметров музыкальных агрегаторов для ликвидации информационной асимметрии в медиаиндустрии.

2.1. Потенциал проекта: Заключается в снижении транзакционных издержек, минимизации юридических и финансовых рисков правообладателей за счет создания готового к эксплуатации программного комплекса. Система обладает высоким потенциалом масштабируемости, позволяя оперативно расширять состав анализируемых объектов и гибко корректировать весовые коэффициенты критериев при изменении рыночных трендов.

2.2. Визуализация данных: Создать адаптивный Single Page Application (SPA) интерфейс с использованием CSS Grid/Flexbox, обеспечивающий мгновенный контекстный поиск, каскадную фильтрацию «на лету» и наглядное представление экспертных заключений (плюсов, минусов и рекомендаций) с цветовой и числовой дифференциацией балла эффективности.

2.3. Многокритериальный анализ: Выявление, классификация и декомпозиция ключевых параметров оценки дистрибьюторов (коммерческих, технико-логистических и сервисных) для построения математической модели средневзвешенной многокритериальной оценки.
ЦЕЛИ МНОГОКРИТЕРИАЛЬНОГО АНАЛИЗА И СВЕРТКИ

Формализация признаков (Feature Specification): Разделение параметров на непрерывные числовые величины (комиссия, дни выплат), бинарные флаги (интеграция с VK, TikTok) и экспертные оценки.

Декомпозиция весовых коэффициентов: Определение степени влияния метрик на безопасность правообладателя с выделением наивысшего приоритета для надежности выплат, скорости транзакций и техподдержки.

Обоснование математической модели: Внедрение метода линейной взвешенной свертки частных критериев эффективности для приведения разнородных параметров к единой стобалльной шкале.

Алгоритмизация экспертных триггеров: Настройка логических условий на бэкенде для автоматического отнесения показателей к преимуществам (плюсам) или недостаткам (минусам) на основе заданных пороговых значений.

Аналитическая предикция и масштабирование: Генерация персональных рекомендаций в зависимости от масштаба музыкального каталога (количества артистов) и обеспечение гибкого изменения весов без остановки сервера и миграции базы данных.
